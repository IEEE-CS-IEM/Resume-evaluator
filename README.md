# 🧠 Resume Evaluator Backend

A FastAPI-based backend system for handling KYC (Know Your Candidate) submissions and job description analysis. Part of a larger collaborative resume screening platform.

---

## 🚀 Features

- ✅ Submit KYC (user info + social profiles)
- 🔍 Fetch, update, or delete user KYC data by email
- 🧠 [Planned] Analyze job descriptions for skills & requirements
- ☁️ MongoDB Atlas cloud database
- 🧪 Interactive API docs via Swagger

---

## ⚙️ Tech Stack

| Layer | Tech |
|-------|------|
| Backend | [FastAPI](https://fastapi.tiangolo.com) |
| Database | [MongoDB Atlas (Cloud)](https://www.mongodb.com/cloud/atlas) |
| Language | Python 3.11 |
| Dependencies | `pymongo`, `python-dotenv`, `pydantic`, `uvicorn` |
